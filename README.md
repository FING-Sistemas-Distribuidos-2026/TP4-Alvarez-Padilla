## Implementación del patrón request

Implementamos el patrón request-reply, el cliente en Python y el servidor en Java.

Para ejecutar el ejemplo, se debe clonar el repositorio. Para el cliente (python), se debe entrar a `code/client/` e instalar los requerimientos con `pip install -r requirements` ya sea en un entorno virtual o globalmente. Luego ejecutar `python client.py`.

Para el servidor (java), hay que entrar en `code/server/` y allí compilar el programa con el script de utilidad `compile.sh` o `compile.bat` dependiendo del sistema operativo. Luego ejecutar el script `run.sh` o `run.bat` para iniciar el servidor.
